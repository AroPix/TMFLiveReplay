# TMFLiveReplay
Mod to show replays from TMX as ghost in realtime

## Installation

### Windows

Run the following in PowerShell to add the mod to TMLoader:

```powershell
irm https://raw.githubusercontent.com/AroPix/TMFLiveReplay/master/modloader/install.ps1 | iex
```

### Linux

> **Note:** The Linux script is only adapted for **TrackMania United Forever (TMUF)** installed through **Lutris** using the [TMUF with TrackMania ModLoader install script](https://lutris.net/games/install/38956/view).

Run the following to add the mod to TMLoader:

```bash
bash <(curl -s https://raw.githubusercontent.com/AroPix/TMFLiveReplay/master/modloader/install.sh)
```
